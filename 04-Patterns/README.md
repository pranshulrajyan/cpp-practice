# C++ Pattern Problems

This folder contains pattern-printing programs written in C++ to practice:

- Nested loops
- Pattern logic
- Character manipulation
- Space handling
- Problem-solving fundamentals

## Patterns Included

- Square Numbers
- Square Stars
- Square Alphabets
- Counting Square
- Star Triangle
- Number Triangle
- Alphabet Triangle
- Reverse Number Triangle
- Floyd's Triangle
- Inverted Number Triangle
- Inverted Alphabet Triangle
- Pyramid Pattern
- Hollow Diamond Pattern
- Butterfly Pattern

## Learning Outcome

These problems helped build a strong foundation in loops and logical thinking before moving on to Data Structures and Algorithms.
